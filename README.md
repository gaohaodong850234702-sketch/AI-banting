# AI伴听 · V0.1.1 Demo（真实本机 ASR）

听见世界，也记住自己。根据「调研AI伴听功能」对话及 V0.1 PRD 实现的本地交互演示。

## 启动

需要 Node.js 20 或更高版本。前端不需要 npm 依赖；语音识别使用本机 Python 环境与 Whisper small 模型。当前工作区已安装，正常使用只需启动预览。

```sh
npm run dev
```

打开 http://127.0.0.1:4317 。服务仅监听本机。可用 `PORT=4318 npm run dev` 修改端口。麦克风需要浏览器授权，使用 localhost / 127.0.0.1 或 HTTPS。

## 建议体验路径

1. 首页点击「继续伴听」，播放内置中文音频。
2. 按住「说说我的想法」录音，松开后自动保存、续播并在本机转成文字；也可以点击开始，再点击完成。首次需要麦克风权限。如果第一次授权时已经松开，授权后再次按住即可。识别完成自动显示详情；也可关闭处理窗口继续听，在后台等待结果。
3. 点击「不方便说话？打字记下」体验文字输入。记录时暂停音频，保存后恢复之前的播放状态。
4. 点击思考卡片，查看上下文、原话和整理预览；可播放原始录音、补充或修订文字。修订不会覆盖最初保存的文字。
5. 点击「结束本次，看看收获」，查看本次收听回顾并导出 Markdown。
6. 导入自己的 MP3 / M4A / WAV（最大 100 MB），刷新后仍可播放与回顾。音频库支持类型筛选、搜索；思考页支持关系筛选、关键词搜索。

## 实现与演示边界

| 能力 | 当前状态 |
| --- | --- |
| 播放、倍速、前后 15 秒、拖动定位、时间轴思考标记 | 真实可用 |
| 导入音频、真实麦克风录音、原始录音回放 | 真实可用；取决于浏览器格式和麦克风权限 |
| 文本记录、原话保留、修订、删除、回顾与导出 | 真实可用 |
| 音频和录音持久化 | IndexedDB，仅当前浏览器 |
| 文字与播放位置持久化 | localStorage，仅当前浏览器 |
| 默认前 45 秒上下文 | 保存真实起止时间并可回听；示例文字按相交段落展示，非逐字时间对齐 |
| 原音频 ASR | 未接入；个人导入音频不会生成虚构转写 |
| 用户语音转写 | 真实本机 Whisper small / faster-whisper ASR，默认启用。无需 API Key、无云端计次费用。支持重试、无语音与失败反馈 |
| AI 理解 / 关系分类 | 示例记录为预置解读；新记录为本地规则整理，明确标为「非 AI」 |
| 收听摘要 | 示例音频使用预置内容提要；用户思考按原话和时间排列，问题按关键词摘录 |
| 长期认知演变、多端同步、外部平台抓取、耳机快捷键 | 未实现，属于后续范围 |

所有内置音频脚本为 Demo 原创，使用 macOS Tingting 合成语音生成，非真实播客、会议或用户经历。内置思考标为示例。录音识别在本机进行；仅首次安装下载开源模型。临时识别文件在处理后自动删除，原始录音仍由浏览器保存。每条录音最多 3 分钟，接口最大 12 MB。浏览器数据导出只含文字与元数据，不含音频二进制。清除浏览器数据会丢失本地记录。

## 项目结构

- `src/app.js`：页面、播放与捕获流程、交互控制。
- `src/asr.js`：同源本机识别请求与错误处理。
- `backend/asr_worker.py`：常驻 Whisper 模型，VAD 语音检测与中文识别。
- `backend/asr-service.mjs`：Python 工作进程、就绪状态、超时与并发限制。
- `backend/asr-http.mjs`：录音上传接口、格式校验与临时文件清理。
- `src/core.js`：上下文窗口、思考对象、规则整理、回顾导出。
- `src/storage.js`：IndexedDB 音频存储。
- `src/styles.css`：响应式界面与原创几何封面。
- `src/catalog.json`：示例音频与分段时间轴。
- `public/audio/`：三段可离线播放的中文示例。
- `docs/PRD-v0.1.md`：引用对话中的完整 PRD。
- `docs/验收记录.md`：实际验证结果与未验证范围。

## 检查与构建

```sh
npm test
npm run check
npm run build
# 预览服务启动后，测试实际中文识别
npm run test:asr
```

构建将前端静态文件输出到 `dist/`。真实 ASR 需要运行项目的 `node server.mjs` 与 Python 工作进程；仅托管静态文件无法语音识别。本项目未部署到公网。

`node scripts/generate-audio.mjs` 可在具备 macOS `say` 和 FFmpeg 的环境中重建演示音频，日常运行不需要这些工具。

## 在另一台机器安装免费本机 ASR

安装 Node.js 与 uv，然后运行：

```sh
npm run setup:asr
npm run dev
```

安装约 461 MB 的多语言 Whisper small 模型以及隔离的 Python 依赖。模型下载使用官方 Hugging Face 源，分段下载后校验 SHA-256。运行时强制离线加载模型，不调用任何收费 API。`curl` 用于下载模型。

可在「设置与数据」检查就绪状态；`GET /api/asr/status` 也可检查。`POST /api/asr/transcribe` 接收原始录音二进制，并返回文字、分段、处理耗时。服务只监听 127.0.0.1，仅接受本页同源请求。

本机 ASR 当前固定识别中文，其他语言与实时流式识别未实现。识别可能听错字，可修订；原始录音与首次保存的转写会保留。关系标签与思考解读依然为本地规则，未接入生成式大模型。

开源实现：[faster-whisper](https://github.com/SYSTRAN/faster-whisper)。模型：[Systran/faster-whisper-small](https://huggingface.co/Systran/faster-whisper-small)。
