# AI伴听 V0.1 Demo 验收记录

验证日期：2026-09-27。浏览器：Tabbit / Chromium，桌面 1440×1000、手机布局 390×844。

## 已通过

- 首页、音频库、伴听播放器、思考详情、收听回顾、设置与数据页面可操作。
- 三段原创中文合成音频时长约 94 / 51 / 54 秒，文件非空，分段时间轴连续。
- 浏览器实际播放推进、播放/暂停、切换 1.25 倍速。
- HTTP Range 返回 206，请求 100 字节，响应 100 字节。
- 文字记录时原音频暂停，保存后恢复之前的播放状态。
- 文字记录绑定前 45 秒范围；刷新后记录仍存在。
- 修订展示文字后，可展开查看最初保存的文字，原话未被覆盖。
- 本次收听回顾包含本次记录，Markdown 导出文件在下载目录存在，已读取核对内容。
- 导入约 51 秒 MP3，浏览器实际播放；刷新后从 IndexedDB 恢复 Blob，仍可解码。
- 音频库关键词搜索返回正确结果。
- 模拟拒绝麦克风权限，展示权限原因，能切换文字记录并完成保存。
- 使用合成音频流驱动真实 MediaRecorder，保存出 12,854 字节录音；刷新后可加载并实际回放。未启用用户物理麦克风。
- 长按录制、松开保存的流程通过浏览器真实指针事件验证。
- 对已明确核对 ID、标题和关联记录的本轮 E2E 测试音频执行删除，关联测试记录一并移除；单条测试思考删除通过。保留其他数据。
- 390px 手机首页无横向溢出，已查看实际截图。
- 测试过程未观察到浏览器 JavaScript 异常。
- `npm test`：7 个核心行为测试通过。
- `npm run check`：JavaScript 语法检查通过。
- `npm run build`：静态产物输出到 `dist/`。

## 未验证 / 能力边界

- 全量清空浏览器数据的实测被自动审批拦截，原因是可能误删已有用户数据；没有执行全量清空，改用事先核对过的本轮测试记录验证局部删除。
- 物理麦克风、蓝牙耳机、iOS Safari、安卓浏览器和真实移动设备未测试。录音路径已使用真实浏览器 MediaRecorder 与合成音频流验证。
- 可选 Web Speech API 未使用真实个人语音测试；默认关闭，不承诺离线或跨浏览器识别。
- 只实测了 MP3 导入；M4A / WAV 导入依赖浏览器解码，提供失败提示。
- 全量清空、删除单独原始语音、JSON 数据导出未执行端到端验证。
- 无后端 ASR、大模型调用、账号、多端同步和公网部署。
- 示例上下文按相交段落展示，文字可能跨过录音触发点；真实回听时间范围绑定前 45 秒。界面与导出中明确标注非逐字对齐。
- 清理后保留一条无思考的测试收听历史，未清空其他会话。首页恢复为三段示例音频和两条示例思考。

## 2026-10-03：真实本机 ASR 增补验收

- 已在项目隔离 Python 环境安装 faster-whisper 1.2.1、PyAV 16.0.1 与 OpenCC 0.1.7。固定 PyAV 版本，修复新版 PyAV 19 不接受 `metadata_errors` 导致真实录音解码失败的问题。
- Whisper small 官方转换模型下载完成，483,546,902 字节；SHA-256 为 `3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671`，已校验一致。
- `/api/asr/status` 返回 `ready: true`、`offline: true`。
- 用原创中文合成语音（约 9.4 秒）测试真实 ASR：输出“我以前总想先确定方向在行动,这让我想到,可以先做一个小项目,用真实的体验帮助自己做选择。”，识别约 1.7 秒。与原脚本相比，“再行动”识别成了“在行动”，说明转写有实际结果但仍可能有同音字误差。
- 浏览器注入上述有真实中文语音内容的音频流，经过真实 MediaRecorder 编码为浏览器录音、上传到本机 ASR 后，显示相同的真实识别文字。无 mock 转写结果、未启用物理麦克风。
- 完整流程通过：记录时暂停 → 结束后续播 → 展示转写 → 原录音和文字保存 → 刷新后仍可查看及回听。浏览器流程识别耗时 1,766 ms，未观察到 JavaScript 异常。
- 本机模型暂不可用时，界面保留录音、显示失败原因与重新识别入口，不生成虚构的用户表达。
- 2 秒静音录音返回空文字、`noSpeech: true`，未编造内容。
- `npm run test:asr` 使用固定中文语音测试文件运行真实模型，核对“确定方向”“小项目”“体验”等词，已通过；测试文件保留于 `tests/fixtures/asr-zh.wav`。
- 14 项自动测试、语法检查、静态构建通过。
- 本次仅接入用户思考录音的本机 ASR；原音频整段 ASR 与生成式 AI 解读仍未实现。
- 重试功能增补：先前失败的无语音录音重新识别得到 `no-speech`；有文字的录音重新识别前展示覆盖修订文字提示，重新识别后首次原文仍保留。
