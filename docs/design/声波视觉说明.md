# 声波精灵视觉说明

2026-10-08，使用内置 GPT Image 工具生成，未使用 CLI/API fallback。

视觉参考：`wave-companion-gpt-image.png`。原图保留于 Codex generated_images，并复制到本项目；仅用于设计追溯。运行页面使用 Canvas 动态绘制的半透明丝带，不把静态图当成真实音频波形。

风格：米白背景，暖橙、浅金、鼠尾草绿与轻微青色交叠，细亮边、柔和光晕，无角色五官、无球体、无柱状均衡器。

行为：待机缓慢流动；用户点击现有录音入口才唤醒麦克风，复用该 MediaStream，通过本机 Web Audio AnalyserNode 读取实时能量。音量影响波幅与流动速度，停顿时回落；不监听唤醒词、不额外申请麦克风、不播放麦克风音频。

减少动态效果时保持静态波形；页面隐藏时暂停绘制。录音结束或切换文字时断开分析节点并关闭分析用 AudioContext，录音流仍由原录音流程管理。
