# AI伴听 · 声波陪你开始

日期：2026-10-08。基于 V0.2 当前代码，分支 `feat/onboarding-companion`。
状态：核心引导已接入 V0.2。本轮交付首次邀请、播放/记录/找回主线、跳过/重开、刷新恢复、真实音量驱动的声波和移动端适配。本文其余 API 逐字段引导、关联/问答/阶段回顾情境提示仍为后续方案。用户已明确：使用抽象声波，不需要具象角色；待机缓慢波动，录音唤醒后跟随实际声音快速变化。

## 目标与判断标准

新用户无需读说明书，能独立完成：选一段声音 → 播放 → 留下自己的想法 → 在记录里找到原话与对应音频。
配置过模型的用户还能看懂 AI 理解与原话的区别，并知道可以纠正。
首轮不要求听完节目，不要求体验全部功能，也不以点完“下一步”作为学会的证据。

当前首页提供四条工作流、API 配置与五期节目，但这些入口同时出现，缺少明确的第一步。
播放器同时支持按住录音、点击录音与文字输入；新用户不容易知道哪种最适合先试。
文字保存、ASR、模型理解和历史关联是不同阶段，需要把“已保存”与“AI 已完成”说清楚。

## 体验主张

让同一条声波带用户完成一件真实的小事。保留用户最初提到的陪伴感与连贯指引，通过声波的形态变化表达状态。

- 一条柔和、连续的抽象声波，无眼睛、耳朵、肢体和人物轮廓；暖橙与鼠尾草绿沿用现有页面色彩，可在交接处出现柔和渐变。
- 展开后是横向半透明丝带状声波；收起后成为帮助按钮内的短波纹。波形在静态下也能识别，不依赖 3D、视频或持续粒子效果。GPT Image 视觉参考与完整提示词保存在 `docs/design/`。
- 声波、简短提示、一个明确操作对象组成一次引导；提示通常一到两句，主操作直接写动作。声波不替代可读文字和真实按钮。
- 首次只邀请一次：“陪你留住第一个想法。我们先听一小段？”主按钮“带我开始”，次按钮“我自己逛逛”。
- 提示文字固定、可审核。无需为了引导额外调用大模型；真实功能仍走现有工作流。

## 第一条想法：主线脚本

| 时刻 | 声波的位置与提示 | 用户操作与推进条件 |
| --- | --- | --- |
| 初次进入 | 首屏内容侧边：“听到有感触的地方，留下一句自己的想法。我陪你试一次。” | 接受引导才开始；跳过后缩到帮助入口，不挡使用 |
| 选声音 | 第一张节目卡的“从推荐片段开始”旁：“从这里听一小段；有想法时随时记下。” | 用户点击后进入播放器；收到真实播放事件再推进，播放失败保留本步 |
| 听一听 | 播放器边缘安静停留：“先听听。想到什么，就点‘说说我的想法’。” | 不按倒计时催促，不自动暂停音频；录音和打字都能继续 |
| 留想法 | 录音按钮旁展开；第一轮主推点击开始、点击完成：“点一下开始说，说完再点完成。也可以打字。” | 用户自行启动麦克风；录音中收起说明，不遮停止按钮。文字为空或用户取消不算完成 |
| 看保存 | 新记录附近：“这句话收好了，也记下了你当时听到的位置。” | 确认持久化成功才进入；语音待识别时改为“录音已保存，正在转成文字” |
| 看理解（可选分支） | 记录详情中先指原话，再指 AI 区域：“上面是你的原话。下面的理解不准确时，可以纠正。” | 只在真实结果已返回时显示；不要求用户点击“理解准确”，允许补充、纠正或继续听 |
| 找回来 | “我的思考”入口旁：“以后从这里，就能找到刚才留下的想法。” | 用户打开本人刚保存的记录；结束首轮，提示“你已经会用了，继续听吧”并收起 |

用户可通过任意等价入口完成操作，不限定必须点高亮的那一个按钮。状态推进依据真实结果，不依据动画结束、固定等待时间或按钮点击次数。

## API 与异常：不要让初次使用卡住

- 未配置 API：默认先体验播放和记录；保存后说明“原话已保存。连接 AI 后，还能帮你理解和关联。”提供“连接 AI”与“先继续听”。首轮基础引导可以独立完成。
- 用户选择连接 AI 后，才进入设置引导：地址、模型、密钥、启用说明、保存和测试。只有当前配置真实测试成功才显示连接成功。引导不读取、复述或收集密钥。
- 已配置但未验证：不声称连接正常；测试与分析继续遵守现有用户启用状态。引导自身不代用户开启服务、不触发重试。
- 网络或模型失败：“原话还在，AI 暂时没完成。”保留错误和手动重试入口；允许跳过理解继续找回记录。
- 麦克风拒绝或不可用：“可以先打字，一样能留下想法。”不反复申请权限。
- ASR 慢或失败：区分录音已保存和文字未完成；可继续听、手动补文字或重试。等待时声波保持低幅静态，不循环催促，不伪装成仍在录音。
- 没有任何音频或推荐节目不可用：就地切换到导入音频引导，不指向消失的节目卡。
- 保存失败：停留在编辑/录音处理流程，保留可恢复内容，不能显示庆祝或引导完成。

## 后续功能：等到有用时再出现

| 场景 | 提示 | 触发原则 |
| --- | --- | --- |
| 第一条真实关联返回 | “这两次想法可能有关。看看原话，再由你判断。” | 至少两条可用记录且确实返回关联；空关联不庆祝、不编造 |
| 主动打开“问问过去的我” | “问一个现在关心的问题，我会从你留下的话里找依据。” | 无记录时给记录入口；一条记录也可以问，不人为锁定功能 |
| 主动打开阶段回顾 | “选一段时间，回看看过的内容让你想到了什么。” | 不自动生成、不自动发起模型请求；少量记录不承诺成长或变化 |
| 用户迷路 | 点击带“使用帮助”标签的短波纹按钮，显示“继续上手 / 这个页面怎么用 / 收起引导” | 只解释当前场景；设置里保留“重新体验引导”与关闭入口 |

## 灵动的规则

声波始终保留相同色彩、线条与运动节奏；路由切换后承接上一句和上一个动作。灵动来自对用户动作的回应。

| 状态 | 动作 | 节奏 |
| --- | --- | --- |
| 初次见面及待机 | 半透明丝带状声波低频流动 | 不随播客音量跳动；页面隐藏时暂停绘制 |
| 指路 | 声波平滑移到目标旁，目标出现柔和描边 | 只在新目标出现时播放一次；约 350ms；跨远距离淡出并在目标处展开 |
| 用户录音 | 起伏幅度与流动速度跟随本机实际录音音量 | 收起说明，不发出音效；复用现有录音流，不额外申请麦克风；停顿时回落 |
| 已保存 | 波峰舒展一次，收成平稳短线 | 约 450ms；仅保存成功触发 |
| 处理失败 | 停稳，保留可读的说明和操作 | 不闪烁或剧烈抖动；不只靠颜色表示错误 |
| 引导完成 | 声波缩回带文字的帮助入口 | 一次短动效，之后不自动弹出 |

不加养成、签到、积分或随机闲聊。日常收听不自动出声，不持续绕页面游动，不盖住文字、录音或播放控制。声波不会在整页四周常驻闪光。
用户开启减少动态效果时，取消位移和振幅变化，保留静态波形、目标描边与文字。待播放、正在播放、正在录音必须有明确文字，不能让同一条动效混淆三者。

## 连贯性、移动端与无障碍

- 桌面气泡锚定当前操作对象，先计算可视范围再决定左右/上下；目标被遮挡时等待用户关闭弹窗或切换提示位置。
- 页面滚动或窗口缩放时更新位置；必要时在用户接受本步后滚动到目标。普通浏览不抢滚动位置。
- 录音、文字输入和记录详情使用原生 dialog；引导需要在活动 dialog 内渲染对应提示，避免被 top layer 遮挡。
- 手机用播放器上方的紧凑提示条配短声波，不在窄屏上堆叠悬浮大气泡。软键盘打开时收起辅助说明，保留输入与保存按钮。
- 首次邀请使用可跳过的原生弹窗；进入引导后不锁页面、不自动夺走键盘焦点。提示用温和的屏幕阅读器播报；声波本身为装饰，帮助按钮有可读名称。
- 随时跳过；刷新可恢复进度。退出后不再主动弹窗；重新开启会校验关联记录和页面是否仍存在。
- 已有真实记录的用户不强制走首次流程，只显示轻量入口。用户本机已有体验数据要原样保留。

## 实现落点

`src/onboarding.js` 与 `src/onboarding.css` 管理提示和定位，`src/onboarding-state.js` 管理状态，`src/wave.js` 用 Canvas 绘制半透明丝带。Web Audio 只读本机音量，随录音结束释放节点；不接入音频输出，不监听唤醒词。复用现有字体、按钮、色彩。
`app.js` 只接入稳定目标标记和真实事件：进入页面、播放成功、开始记录、持久化成功、打开指定记录。
`memory.js` 提供当前模型/工作流状态，只读订阅分析成功、失败、关联结果；不轮询 DOM 文案猜测状态。
先检查并确保 `save()` 的返回值和 IndexedDB 写入结果可作为成功条件，不能把当前 toast 文案当成保存证据。
为重要控件添加 `data-guide` 标记，避免按 CSS 排名或中文文案定位。

状态建议：`idle → welcome → choose → listen → capture → saved → inspect → find → complete`。
`paused / dismissed` 独立管理；配置和理解是可选分支，语音失败有文字路径。`inspect` 只展示当前真实可用内容。
单独存储引导版本、阶段、关闭状态、已提示功能和本次记录 ID；不存用户原话或模型密钥，不混入个人记忆，不进入模型请求。
若记录被删除、音频被移除或用户跨页，重新判断能执行的动作；不清空用户数据来重演引导。

## 分阶段交付与验收

第一版：抽象声波、首次邀请、播放/文字/语音主线、保存与找回、模型状态分支、跳过/恢复、移动端及减少动态效果。
第二版：实际关联提示、问答/回顾按场景帮助与更细致的波形过渡。基础功能仍全部可直接使用。

验收时至少覆盖：

1. 全新浏览器、无 API：能播放、保存文字、找回记录、结束基础引导；没有伪造分析。
2. API 已启用：基于真实完成状态展示理解；分析慢或失败不影响已保存记录和继续听。
3. 麦克风拒绝、取消录音、空文字、保存失败：不误推进；切换文字路径可继续。
4. 自由跨页、刷新、跳过、删除刚保存记录：位置和进度可恢复，不困在不存在的目标上。
5. 390px 与 320px、软键盘、滚动、dialog、底部播放器：关键操作不被覆盖；键盘能操作所有引导控制。
6. 减少动态效果生效；引导关闭后不反复出现；重开引导不清空数据、不默认发起 API 请求。
7. 邀请未接触项目的人试用，观察是否无需口头帮助就能保存并找回第一条想法。记录实际卡点，不预设转化率或宣称已改善。

实际验证范围见 `docs/新手引导验收记录.md`。后续功能不因方案中列出而视为已实现。
