# 真实设备录音验收

状态：**待执行**。本文件提供步骤与记录格式，不代表任何物理麦克风或 iOS 已通过。

## 前提与范围

桌面由 `npm start` 提供完整服务，并准备真实节目和本机 Whisper。先检查ASR就绪；测试个人录音前关闭不需要的模型调用。使用自愿录制的测试讲话，记录真实耗时和故障，不把合成波形或模拟ASR响应作为设备证据。

当前 `server.mjs` 只监听 `127.0.0.1`；模型和ASR接口均要求本机同源访问。**iPhone 不能直接通过 Mac 的局域网地址访问现有完整服务。** iOS完整链路验收还依赖受支持的设备接入方案，本次未实现。不要为测试直接移除同源限制或把本机密钥服务公开。桌面浏览器缩到390px仅证明布局，不证明iOS可用。

## 验收步骤

每项记录通过/失败/受阻、现象、复现步骤、相关日志及耗时；没有执行的项目保持“待测”。

| 场景 | 操作 | 预期行为 | 当前状态 |
|---|---|---|---|
| 正常核心链路 | 播放节目→录制15–30秒讲话→停止→转写→从我的思考找回→回听原录音 | 暂停点正确；仅创建一条记录；录音可回听；可核对转写 | 待测 |
| 音量响应 | 分别静音、轻声、正常讲话，各录3次 | 声波有可辨别响应；静音回落；报告环境底噪影响 | 待测 |
| 噪声与耳机 | 背景人声、风扇声；内置麦克风和耳机各测 | 记录转写错误、音量饱和与听不清情况；不预设通过 | 待测 |
| 权限拒绝 | 新浏览器拒绝麦克风，再切换文字 | 原音频位置保留；可用文字完成记录并找回 | 待测 |
| 中断 | 录音中切换标签、设备锁屏或接到系统中断，再返回 | 明确实际状态；不误报已保存；检查残留音轨和重复记录 | 待测 |
| 时长边界 | 持续录音至应用约175秒自动停止 | 产生一条可回听记录；可继续播放节目和重试转写 | 待测 |
| 保存失败 | 在独立测试空间模拟存储配额不足，再恢复并重试 | 保留草稿/当前页录音；不重复创建记录 | 待测 |
| 转写失败 | 使用未就绪ASR，保存录音后恢复服务并重试 | 保留原录音、显示失败原因；可重试或补充文字 | 待测 |
| 转写内容 | 讲话含“还没有决定”“如果……才……”及人名 | 人工核对否定、条件和说话人；记录错误，不只看是否返回文字 | 待测 |
| iOS输入与布局 | 真机打开文字输入、日期与音频选择，弹出键盘并滚动 | 控件可点击；保存按钮可达；无横向溢出 | 受接入前提阻挡 |
| 减少动态效果 | 开启系统减少动态效果后录音 | 界面仍能明确告知录音状态；停止后麦克风被释放 | 待测 |
